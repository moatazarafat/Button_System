Choose the right button

Use one primary button per screen. Everything else should be quieter.

ButtonClassUse it for
btnThe main action on a screen, such as Save, Buy or Sign up.
btn btn--secondaryA second choice next to the main action.
btn btn--ghostLow-key actions inside text, toolbars or cards.
btn btn--dangerActions that remove data or cannot be undone.

Add it to your site

Copy the CSS into your stylesheet, then use the HTML below. The CSS tab matches the color, radius and size you chose above.


    
<button class="btn">Save changes</button>
<button class="btn btn--secondary">Cancel</button>
<button class="btn btn--ghost">Learn more</button>
<button class="btn btn--danger btn--sm">Delete</button>
<a href="/signup" class="btn btn--lg">Sign up</a>
<button class="btn" disabled>Unavailable</button>
